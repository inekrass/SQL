ManticoreSearch reviews checks
==============================

1. RT-индекс reviews создан
---------------------------

Команда:
docker compose exec manticore mysql -h0 -P9306 -e "DESC reviews"

Результат:
+-------------+-----------+----------------+
| Field       | Type      | Properties     |
+-------------+-----------+----------------+
| id          | bigint    |                |
| title       | text      | indexed stored |
| body        | text      | indexed stored |
| product_id  | uint      |                |
| customer_id | uint      |                |
| rating      | uint      |                |
| created_at  | timestamp |                |
+-------------+-----------+----------------+

4. Полнотекстовый поиск
-----------------------

Команда:
SELECT id, product_id, customer_id, rating, title
FROM reviews
WHERE MATCH('otlichnyy tovar rekomenduyu')
LIMIT 5;

Результат:

| id     | product_id | customer_id | rating | title           |

5. Фильтрация по рейтингу и товару
----------------------------------

Команда:
SELECT id, product_id, customer_id, rating, title
FROM reviews
WHERE rating >= 4 AND product_id = 42
LIMIT 5;

Результат:
+--------+------------+-------------+--------+---------------+
| id     | product_id | customer_id | rating | title         |
+--------+------------+-------------+--------+---------------+
| 200001 |         42 |           1 |      5 | Great product |
+--------+------------+-------------+--------+---------------+


6. Фасетный поиск по рейтингу
-----------------------------

Команда:
SELECT id, rating
FROM reviews
LIMIT 1
FACET rating ORDER BY count(*) DESC;

Результат:

| id     | rating |
