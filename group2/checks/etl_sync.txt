PostgreSQL -> ClickHouse ETL checks
===================================

1. Таблица ClickHouse создана
-----------------------------

Команда:
docker compose exec clickhouse clickhouse-client \
  --user analytics_user \
  --password analytics_password \
  --database analytics \
  --query "DESCRIBE TABLE analytics.orders_analytics"

Результат:
order_date      Date
order_id        UInt64
customer_name   String
region          LowCardinality(String)
product_name    String
category        LowCardinality(String)
quantity        UInt32
price           Decimal(12, 2)
line_total      Decimal(12, 2)
order_status    LowCardinality(String)

Вывод: таблица плоская и денормализованная, как нужно для аналитики.

----------------------

docker compose exec -T postgres psql -U shop_user -d shop -c "SELECT count(*) AS source_rows FROM order_items;"

4. Данные в ClickHouse
----------------------

Команда:
docker compose exec clickhouse clickhouse-client \
  --user analytics_user \
  --password analytics_password \
  --database analytics \
  --query "SELECT count(*) AS rows_count FROM analytics.orders_analytics"

Результат:
1000002

Вывод: количество строк в ClickHouse совпадает с количеством строк-источников в PostgreSQL.


5. Аналитический запрос: топ-5 категорий по выручке
--------------------------------------------------

Команда:
SELECT
    category,
    sum(line_total) AS revenue
FROM analytics.orders_analytics
GROUP BY category
ORDER BY revenue DESC
LIMIT 5;

Результат:
Category 1	15016694091.25
Category 11	15013268076.75
Category 6	14979888465.65
Category 16	14963920396.20
Category 10	12059496105.44


6. Аналитический запрос: дневная динамика заказов
------------------------------------------------

Команда:
SELECT
    order_date,
    countDistinct(order_id) AS orders_count,
    sum(line_total) AS revenue
FROM analytics.orders_analytics
GROUP BY order_date
ORDER BY order_date
LIMIT 10;
