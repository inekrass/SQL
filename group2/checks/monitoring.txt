Grafana monitoring checks
=========================

1. Сервисы мониторинга запущены
-------------------------------

Команда:
POSTGRES_PORT=55432 docker compose up -d metrics-exporter prometheus grafana

Проверка:
docker compose ps

Результат:
group2_metrics_exporter   python:3.11-slim        Up   0.0.0.0:9180->9180/tcp
group2_prometheus         prom/prometheus:v2.55.1 Up   0.0.0.0:9090->9090/tcp
group2_grafana            grafana/grafana:11.3.1  Up   0.0.0.0:3000->3000/tcp

docker compose exec metrics-exporter python -c "import urllib.request; print(urllib.request.urlopen('http://localhost:9180/metrics').read().decode()[:3000])"

3. Prometheus видит exporter
----------------------------

Команда:
docker compose exec prometheus wget -qO- 'http://localhost:9090/api/v1/targets?state=active'

Результат:
target: metrics-exporter:9180
job: pipeline_metrics
health: up
lastError: ""

4. Что показывает dashboard
---------------------------

PostgreSQL:
- активные подключения;
- транзакции/сек;
- размер таблиц.

ClickHouse:
- строки в orders_analytics;
- запросы/сек;
- статус репликации.

ManticoreSearch:
- количество документов в reviews;
- время поискового запроса.

Pipeline:
- время последней синхронизации;
- количество обработанных записей.

Вывод:
Мониторинг поднят. Prometheus получает метрики от exporter-а, Grafana автоматически создает datasource и dashboard из JSON/provisioning-конфигов.
